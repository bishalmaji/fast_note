# 📝 Flutter Notes App

A clean, offline-first notes application built using Flutter,
focused on performance, clean architecture, and scalability.

## 🚀 Features
- Create, edit, delete notes
- Offline storage (Hive / SQLite)
- Clean Architecture
- Dark & Light theme
- Smooth animations

## 🧠 Architecture
- Presentation → Riverpod / Bloc
- Domain → Use cases
- Data → Repository pattern
